Why Qelvora

A correction layer designed for actual Mac workflows.

01

Works where you write

Use Qelvora from browsers, notes, editors, chat apps, and other macOS surfaces.

02

Local by design

Your selected text is corrected by Ollama on your Mac, not by a hosted writing service.

03

Built for difficult apps

Services, clipboard, Accessibility, and OCR fallback help capture text reliably.

Recommended for

A serious writing utility for sensitive workflows.

Founders and operators

Clean customer replies, investor updates, and internal notes without moving drafts into a hosted editor.

Developers and builders

Keep GitHub issues, support answers, and release notes polished while staying inside your local tools.

Privacy-first teams

Use local Ollama models when a cloud correction service is not appropriate for the text in front of you.

Workflow

Select. Correct. Use.

1

Select text

Highlight the text you want to clean up in any macOS app.

2

Trigger Qelvora

Use the menu bar, hotkey, or Services entry where available.

3

Run locally

The selected Ollama model corrects, rewrites, or translates the text.

4

Copy result

Review the output and place the clean version back into your workflow.

Local-first

For drafts, customer replies, and notes that should stay yours.

Qelvora is intentionally built around local model inference. macOS permissions are used to capture text and support OCR fallback, not to move your writing into a remote correction pipeline.

Local model runtime Corrections and translations run through Ollama on your machine.
Transparent project The Swift source is public and MIT-licensed.
Flexible models Use recommended models, installed tags, or custom model names.

Current release

Install the official macOS build.

The source is free to build. The official DMG is the clean install path with signing, notarization, packaging, and Sparkle updates.
