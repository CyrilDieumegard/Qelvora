Privacy

Built for drafts you do not want to upload.

The correction backend is your local Ollama instance. Qelvora needs macOS permissions to capture text across applications, not to send your writing to a hosted correction service.

Local model runtime

Corrections and translations are generated by models already installed on your Mac.

Native macOS permissions

Accessibility and Screen Recording support selection capture and OCR fallback.

Transparent code

The public Swift project shows how capture, correction, packaging, and updates work.

Flexible model choice

Use recommended models, installed Ollama tags, or custom names such as llama3.1:8b.

FAQ

Practical notes.

Does Qelvora require an internet connection?

Correction runs through your local Ollama instance. Internet access may still be needed to install Ollama, pull models, or download updates.

Why does it need macOS permissions?

Accessibility lets Qelvora work with selected text across apps. Screen Recording enables OCR fallback when an app does not expose selected text cleanly.

Can I use my own model?

Yes. Qelvora can use recommended models, detect installed Ollama models, and accept custom model names.
