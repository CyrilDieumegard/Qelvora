FAQ

Straight answers before you install.

What is Qelvora?

Qelvora is a private local AI writing assistant for macOS. It corrects, rewrites, and translates selected text using Ollama models running on your Mac.

Does Qelvora send text to the cloud?

Qelvora is built around local model inference. The product is designed for workflows where drafts, customer replies, or internal notes should stay on the machine.

Which models work with Qelvora?

Qelvora uses installed Ollama model tags. Local writing workflows can use model families such as Gemma, Qwen, DeepSeek, Kimi, Mistral, Llama, and Phi.

Who is Qelvora for?

Qelvora is useful for founders, developers, support teams, and privacy-first operators who need fast writing cleanup inside normal macOS apps.

The source is free to build. The official DMG is the clean install path with signing, notarization, packaging, and Sparkle updates.

Qelvora needs Ollama running locally. Install Ollama first, launch it once, then download the recommended Gemma 4 4B model from the app.
