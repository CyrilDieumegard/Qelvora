What this means in practice

Qelvora is a local spell checker, local grammar checker, and private writing assistant for macOS. It is designed for short correction workflows: select text, run Qelvora, review the model output, and copy the clean result back into the original app.

The text is processed through the user's local Ollama setup. That makes it useful for emails, customer replies, notes, GitHub issues, support answers, and translations that should not be pasted into a cloud writing editor.

Practical checklist

For local spell checking, start with a short selection rather than a whole document. Ask for correction, clarity, or translation as a narrow task. Then compare the result with the original sentence and make sure the model preserved names, numbers, dates, product terms, and the writer's intent.

This habit matters for SEO, support, product, and developer writing because the best output is not the most rewritten output. The best output is the version that is clearer while still being true to the original context.
