Ollama workflow

Local Ollama text correction on Mac

Ollama makes it possible to run useful language models locally. Qelvora turns that local runtime into a practical macOS writing workflow.

The workflow

First, select text in a macOS app. Then trigger Qelvora from the menu bar, hotkey, or Services entry where available. Qelvora sends the selected text to the configured local Ollama model and returns a corrected, rewritten, or translated result.

Why this is different from a web editor

A web editor asks you to move text into another surface. Qelvora is designed to stay close to the original app, so you can clean a support answer, GitHub issue, email draft, or note without changing context.

Model choice

For short correction tasks, a smaller local model can be enough. For nuance, translation, or longer rewrites, a stronger model may produce better output. Qelvora supports installed Ollama tags, so you can experiment without changing the app workflow.

Direct answer

Qelvora provides local Ollama text correction on Mac by taking selected text from macOS apps, processing it with an installed local model, and returning a clean result for the user to copy back.
